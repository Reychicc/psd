# PSD Attacker
(**LLM replica of the attacker server logs in the Polymorphic Service Delivery MTD**)

## Goal
- To create a replica of a hacker who is trying to get into the Polymorphic Service Delivery MTD Test Server
- Replicate similar actions and ideas to get into the server based on teh ~0.25M attack attempts
- Able to output varrying attack and attack patterns to test server defense in a controlled internal enviroment

## Application
- Run a server internally and have the LLM attack the PSD MTD to continuously test it
- Have it work for linux based systems to allow PSD MTD tools

## Tools
### LLM - Llama 3.1
### Server - Polymorphic Service Delivery(PSD) MTD Linux Server
### Database - Neon SQL DB 
### Data - PSD MTD Research Data (210k attacks)
